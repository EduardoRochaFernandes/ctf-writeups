# Security and content policy

This repository contains study notes only; it ships no application. The relevant concerns are:

- **Spoilers or restricted content:** if you find a CTF flag, room answer, password or paid-course material that should not be public, please open an issue titled "Spoiler" without repeating the content in the issue, and I will redact it.
- **Sensitive data:** do not include real credentials, personal data or live malware in contributions. Packet captures, `.eml` files and samples are git-ignored on purpose.
