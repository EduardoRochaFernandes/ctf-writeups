# Contributing

This is a personal study repository, so I do not expect pull requests, but corrections are welcome.

- Fix factual errors or broken links via issue or PR.
- Start new notes from [`templates/writeup-template.md`](templates/writeup-template.md) and add the room to the index in `README.md`.
- Never include flags, passwords or final answers; use `THM{REDACTED}` or `[redacted]`.
- Run `python scripts/check_writeups.py` before opening a PR.
